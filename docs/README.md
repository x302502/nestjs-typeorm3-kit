## How to read these guides / Cách đọc tài liệu

**EN.** Each guide starts with a one-paragraph overview, then a minimal
runnable example, then a full **API reference** for every public symbol — name,
signature, every option (type, default, required?, description), behaviour
notes, and common pitfalls. Skip to the **API reference** section if you already
understand the feature.

**VI.** Mỗi tài liệu mở đầu bằng một đoạn tổng quan, kế đó là ví dụ chạy được
ngắn nhất, rồi đến **Tham chiếu API** đầy đủ cho từng symbol public — tên, chữ
ký, mọi option (type, mặc định, bắt buộc?, mô tả), ghi chú behaviour, và các
lỗi thường gặp. Nếu bạn đã hiểu tính năng thì nhảy thẳng tới **Tham chiếu API**.
